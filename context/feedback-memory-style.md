---
name: feedback-memory-style
description: Write memories as direct instructions and facts; don't record one teammate's one-off mistakes
metadata:
  type: feedback
---

Write memories as direct instructions and facts: how to do things, and what is true. Don't add notes about a mistake one teammate made once, such as "the most common mix-up" or "if X happens, you probably did Y". The exception is a mistake that is genuinely common and expected to recur.

**Why:** On 2026-10-25 a teammate asked for a "most common mix-up" note (typing keys into the wrong window) to be removed from the beginner guide. They want memory to be direct instructions, not fixes for individual slips.

**How to apply:** When a teammate hits a problem, fix the code or docs if that helps everyone, and keep memory to the plain instruction. See [[team-context]].
